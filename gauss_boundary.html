Prescribed charge on an infinite plane in vacuum, with no external field or volume charge. Height uses a logarithmic slider; its left endpoint is the analytic h → 0 limit.

η(x) = η₀ [1 + a cos(kx)]
Ex = η₀ a sin(kx) e−k|z| / (2ε₀)
Ey = 0
Ez = sgn(z) η₀ [1 + a cos(kx) e−k|z|] / (2ε₀)
C = cos(kx₀) 2J₁(kR)/(kR),   η̄ = η₀(1 + aC)
Φ+ = Φ− = Aη₀ [1 + aC e−kh/2] / 2
Φside = Aη₀ aC [1 − e−kh/2]
Φtotal = Aη₀(1 + aC)

Localized Lorentzian stripe on a uniform background: η(x) = η₀[1 + aL²/(x² + L²)], L = 0.5 m. It is uniform along y, centered at x = 0, and is not periodic. Here η₀ is the background density.

w = L + |z|
Ex = η₀ aLx / [2ε₀(x² + w²)]
Ez = sgn(z) η₀[1 + aLw/(x² + w²)] / (2ε₀)
Ey = 0
B(w) = Re{2L / [w − ix₀ + √((w − ix₀)² + R²)]}
η̄ = η₀[1 + aB(L)]
Φcaps = Aη₀[1 + aB(L + h/2)]
Φside = Aη₀a[B(L) − B(L + h/2)]
Φtotal = Aη̄

B is the exact disk average of Lw/(x² + w²), using the square root with positive real part. Both cap and side integrals are evaluated analytically.

For the sinusoidal sheet, J₁ is the first-order Bessel function. The side expression follows by integrating ε₀Excosθ over the cylindrical wall. For bounded E, its flux vanishes with h because the wall area is 2πRh. The cap area stays fixed. At h = 0 the displayed values are limits of the closed surfaces; the collapsed disk is not itself a closed Gaussian surface.

For a uniform sheet (a = 0), the field is normal everywhere: side flux is already zero at any height. For a varying sheet, side flux can be positive or negative depending on where the cylinder is centered.
